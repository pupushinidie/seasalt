# 翻七

3–10 人的翻牌拼运气桌游，网页联机版。规则书在 `~/Desktop/游戏规则/翻七.md`。线上 https://gulugagame.com/flip7/ 。

## 本地运行

```bash
npm install
npm run dev          # 服务端 :3010，网页 :5183
npm test             # 规则引擎（23 个用例，含 200 局随机对局）
npm run typecheck
node scripts/test-bot.mjs host 机器人 4 --start-at=4   # 陪玩机器人，用法见文件开头
```

## 规则要点

- 94 张牌：数字牌 0–12（每个数字的张数等于它本身，0 有 1 张），冻结 / 翻三 / 二次机会各 3 张，+2 / +4 / +6 / +8 / +10 / ×2 各 1 张。
- 每轮庄家从左手边开始每人明发一张，然后从庄家左手边开始轮流选「要牌」或「停牌」。翻到和自己面前重复的数字就爆掉，本轮 0 分。所有人停牌或爆掉，这一轮结束。
- 凑齐 7 张不同的数字是「翻七」：这一轮立刻结束，他额外 +15，其他没爆的人照常计分。
- 计分：数字相加，加上 +修饰牌，有 ×2 就把（数字 + 修饰）翻倍，再加翻七奖励。
- 某一轮结束时有人总分到 200，游戏结束，总分最高者获胜。

规则书没写死、这里这样处理的地方：

| 情况 | 处理 |
| --- | --- |
| 开局发牌 | 每人恰好发一张（不管是什么牌）。发到行动牌立刻处理，再接着发；还没发到就被冻结的人跳过 |
| 行动牌给谁 | 冻结、翻三只能给还在要牌的人（可以是自己）。只有一个人能接时自动给他，不用选 |
| 多出来的二次机会 | 要给别的、还在要牌、手里没有二次机会的人；没人能接就弃掉 |
| 翻三 | 连翻 3 张，翻到重复就爆、停下。翻到的二次机会马上能用；冻结、翻三、多出来的二次机会（以及残酷模式的修饰牌）等 3 张翻完、没爆，再由被翻的人逐张处理；爆了就作废。中途翻七，这一轮立刻结束 |
| ×2 怎么算 | 按规则书第 6 节：(数字 + 修饰) × 2，再加翻七奖励。官方卡面可能是「只翻倍数字」，待确认 |
| 残酷模式 | 默认开，房主在等候房间可以关。摸到修饰牌要选给谁（可以给爆掉的人）；翻七时选自己 +15，或让一位对手本轮 −15（爆掉的人被罚就是 −15）；所以分数可以是负的 |
| 牌堆 | 跨轮不洗回，摸光了才把弃牌堆洗成新牌堆；两边都空了（几乎不会）要牌的人只能停牌 |
| 庄家 | 第一轮随机，之后每轮轮到下一位 |
| 终局 | 某轮结束时有人 ≥ 200：总分最高者获胜，一样高就并列 |
| 限时 | 每个决定 30 秒。要牌/停牌超时 → 停牌；冻结默认给自己，翻三默认给下一位还在要牌的对手，多出来的二次机会给座位顺序上的下一位，修饰牌留给自己；翻七默认自己 +15。轮到的人离线只等 3 秒。每轮结算画面停 20 秒，在线的人都点「下一轮」就提前开始 |
| 人数 | 3–10 人（规则书的范围），不支持 2 人 |

界面上的小功能：能用的按钮和能选的座位亮起来；选目标时每个人旁边写着本轮分数（翻三还写每张爆的概率）；右边显示「再要一张爆掉」的概率（按牌堆里剩下的牌算，所有牌都是明着翻的，这是公开信息）；快捷键 H / 空格要牌、S 停牌、N 下一轮；页面在后台时标题提示「【轮到你】」；按房间码固定一张牌桌背景。

## 目录

- `packages/game`：纯函数规则引擎（`engine.ts`）和测试。牌堆顺序、弃牌堆、随机数状态只在服务端，`redactGameForViewer` 去掉它们（桌上的牌都是明牌，没有别的隐藏信息）。
- `apps/server`：Socket.IO 房间、计时、重连、语音信令（和其他游戏同一套），加了「残酷模式」房间设置（`room:settings`）和离线玩家 3 秒代打。
- `apps/web`：React 网页。`GameBoard.tsx` 是牌桌：座位按人数和屏幕大小自动选列数和牌的大小（`pickLayout`），宽座位时名字和分数放左边；`cards.tsx` 画牌（牌面是 CSS，数字是像素字体，图标是 PixelLab 小图）。
- `scripts/test-bot.mjs`：陪玩机器人。
- `art/`：`art.py` 出候选（牌桌背景、首页主图、图标、头像），`contact.py` 拼候选总览，`selection.json` 记选中的，`export.py` 导出到 `apps/web/public/art/`，花费记在 `ledger.jsonl`。

## 画面：白天版和夜间版

只有像素风一种画面，配色分夜间（深色，默认）和白天（白底）两种。顶栏「切换白天版 / 切换夜间版」随时切换，记在浏览器的 `gm-pixel-theme` 里；gulugagame.com 上的大厅和各个游戏同源，共用这一个选择。

- 夜间配色就是 `app-pixel.css`（首页和等候房间）和 `flip7.css`（牌桌）本身。白天版由 `apps/web/day-theme.ts`（Vite 插件）在构建时按 `apps/web/day-palette.ts` 的调色表生成；新出现的深色要在调色表里补一行。
- 机械换色不合适的地方在 `apps/web/src/theme-day.css` 里手写。

## 部署

服务器上 `~/flip7`，pm2 进程 `flip7`（端口 3010），网页在 `/var/www/flip7`，Caddy `handle_path /flip7/*`（也在付费网关 `@games` 里）。本机运行 `~/projects/deploy.sh flip7`（服务器拉 GitHub 上的 main）。

pm2 按仓库根目录的 `ecosystem.config.cjs` 直接启动一个 `node --import tsx` 进程跑服务端（不经过 `npm start`）。端口和密钥存在 pm2 里，不进仓库。
