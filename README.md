# 海盐与纸

2–4 人的海边卡牌收集游戏，网页联机版。规则书在 `~/Desktop/游戏规则/海盐与纸.md`，有出入的地方按官方规则（官方规则书 + BGA 官方实现）做，见下面的表。线上 https://gulugagame.com/seasalt/ 。

## 本地运行

```bash
npm install
npm run dev          # 服务端 :3011，网页 :5184
npm test             # 规则引擎（41 个用例，含 300 局随机对局和隐藏信息检查）
npm run typecheck
npm run build:game && node scripts/test-bot.mjs host 机器人 3 --start-at=3   # 陪玩机器人，用法见文件开头
```

## 规则要点

- 58 张牌：对子牌（蟹 9、船 8、鱼 7、鲨鱼 5、泳者 5）、收集牌（贝壳 6、章鱼 5、企鹅 3、水手 2）、乘数牌（灯塔、鱼群、企鹅群、船长各 1）、美人鱼 4。每张牌有颜色，按官方牌表：深蓝 9、浅蓝 9、黑 8、黄 8、绿 6、白 4（就是 4 张美人鱼）、紫 4、灰 4、浅橙 3、粉 2、橙 1（`packages/game/src/cards.ts` 的 `CARD_LIST`）。
- 每回合：拿牌（从牌堆摸两张留一张、另一张丢进弃牌堆；或者拿一个弃牌堆顶上的牌）→ 可以打对子（蟹：翻一个弃牌堆挑一张；船：再来一回合；鱼：摸一张；鲨鱼 + 泳者：偷对手一张）→ 卡牌分 ≥ 7 时可以宣告 STOP 或最后机会。
- 计分：对子每对 1 分（手里凑成的也算），贝壳 0/2/4/6/8/10，章鱼 0/3/6/9/12，企鹅 1/3/5，水手 0/5，灯塔每船 +1、鱼群每鱼 +1、企鹅群每企鹅 +2、船长每水手 +3，美人鱼按颜色张数（第 k 张数第 k 多的颜色）。颜色奖励 = 最多那种颜色的张数。
- 目标分 2 人 40、3 人 35、4 人 30；集齐 4 张美人鱼立刻获胜。

规则书没写清、或和官方有出入、这里这样处理的地方（他选了「全按官方」）：

| 情况 | 处理 |
| --- | --- |
| 开局弃牌堆 | 官方：每轮洗匀 58 张后翻两张，两个弃牌堆各放 1 张（规则书写的是开局为空） |
| 最后机会赌输 | 官方：宣告者只拿颜色奖励，**对手只拿卡牌分**（规则书写的是对手拿卡牌分 + 颜色奖励） |
| 最后机会赌赢 | 宣告者的卡牌分 ≥ 每位对手（平分算宣告者赢）：宣告者拿卡牌分 + 颜色奖励，对手只拿颜色奖励 |
| 牌的颜色 | 按官方牌表（规则书的颜色表粉色写成 3 张，合计 59；官方是 2 张，合计 58） |
| 美人鱼的颜色 | 美人鱼本身算白色：数颜色、颜色奖励、美人鱼计分都算上它 |
| 数颜色 | 手牌 + 面前打出的牌一起数 |
| 最后机会的亮牌 | 宣告者宣告时亮牌，其他人打完最后一回合亮牌；亮出的手牌不能再被鲨鱼偷 |
| 最后一回合 | 其他人各打一回合（拿牌 + 打对子），不能再宣告；打出两艘船照样再来一回合 |
| 牌堆摸空 | 有人回合结束时牌堆空了（又没人宣告）：这一轮作废，谁都不得分，下一轮从他左手边开始。最后机会进行中牌堆空了不作废，照常结算；同一回合里宣告了 STOP 也照常计分 |
| 牌堆只剩一张 | 摸牌时直接留下这一张，不用丢 |
| 有空的弃牌堆 | 摸两张丢一张时必须丢进空堆；两个都空或都不空可以随便选 |
| 效果用不了的对子 | 也能打出来（比如两个弃牌堆都空了还打两只蟹），只计分、不发动效果。打出去的牌也不会被偷 |
| 蟹 | 先选弃牌堆（只看得到堆顶），再翻看整堆挑任意一张；别人只知道你从哪一堆拿了一张。只有一堆有牌就直接翻那一堆 |
| 鲨鱼 + 泳者 | 只能偷手里有牌、手牌没亮出的对手；只有一位能偷就直接偷。偷到哪张只有你和被偷的人知道 |
| 四张美人鱼 | 美人鱼进了手（摸、拿、蟹、鱼、偷）凑够 4 张，马上获胜，不用等回合结束 |
| 终局 | 有人总分 ≥ 目标分，那一轮结算完结束：总分最高者获胜；一样高比最后一轮的得分（法文原版和 BGA 都这样），再一样就并列 |
| 先手 | 第一轮随机，之后每轮从上一轮结束者（宣告的人、或牌堆摸空时那一回合的人）的左手边开始 |
| 限时 | 每个决定 45 秒。超时：拿牌 → 从牌堆摸（牌堆空了拿左边的弃牌堆）；留牌 → 留卡牌分高的那张，另一张丢左边（有空堆丢空堆）；出牌 → 直接结束回合，不打对子、不宣告；蟹 → 选张数多的那一堆，拿分最高的牌；偷 → 偷手牌最多的对手。**连续超时 2 次转托管**：由人机替他打，直到他自己动一下或点「取消托管」；轮到的人离线时等 3 秒后由人机代打（不算超时），用原昵称回来座位交还。每轮结算画面停 25 秒，在线、没托管的真人都点「下一轮」就提前开始 |
| 人数 | 2–4 人（规则书的范围）；扩展（加盐、加胡椒）没做 |

界面上的小功能：能拿的牌上直接写「+N 分」（拿了之后卡牌分多几分）；手牌里能凑成对子的牌抬高、加金边，点一下就打出这一对，悬停对子按钮会把那两张牌抬起来；自己的面板一直显示卡牌分明细、颜色奖励和每种颜色的张数（最多的那种描金边）；最后机会时顶栏有提示条，亮出的手牌摆在对手面板里；快捷键 D 摸牌堆、1 / 2 拿左 / 右弃牌堆、E 结束回合、S STOP、L 最后机会、N 下一轮；页面在后台时标题提示「【轮到你】」。

## 人机（「普通」难度）

- 房主在等候房间的空座位点「加人机」（咕噜一号 / 二号 / 三号，带「人机」标签），一个人也能加满人机开局；「移出」请走。
- 策略在 `packages/game/src/bot.ts`：`botCommand(视角状态, 座位)`，只吃 `redactGameForViewer` 之后的状态（别人的手牌只有张数，弃牌堆只看堆顶，打蟹选好堆才看得到那一堆）。`botAdvice` 同时给一句理由（教程「提示」用）。
  - 拿牌：弃牌堆顶的牌立刻能多拿的分，和「摸两张留一张」的期望比（看不到的牌当作整副牌减去看得到的牌里随机一张）；留分高的，另一张盖住对别人更有用的堆顶。
  - 有对子就打（鱼 → 蟹 → 鲨鱼泳者 → 船）。
  - 宣告：抽样估计对手的卡牌分，比较 STOP / 最后机会 / 继续；这一轮结算会让有人到目标分时按谁会赢来定。
- 强度（`~/projects/qa-reports/tools/bots/sim-seasalt.ts`）见 memory `bots.md`。

## 目录

- `packages/game`：纯函数规则引擎（`engine.ts`）、牌表和计分（`cards.ts`）和测试。牌堆顺序、随机数、种子只在服务端；`redactGameForViewer` 去掉别人没亮出的手牌（只留张数）、刚摸的两张（只有摸牌的人看得到）、弃牌堆里面的牌（只留堆顶；打蟹挑牌的人看得到他选的那一整堆），以及事件里带 `privateTo` 的私密牌（摸到的、蟹拿的、鱼摸的、偷到的）。
- `apps/server`：Socket.IO 房间、计时、重连、语音信令（和其他游戏同一套），人机座位、托管、离线 3 秒后人机代打。
- `apps/web`：React 网页。`GameBoard.tsx` 是牌桌（`pickSizes` 按牌桌高度算牌的大小：手牌最大 128px、张数多时缩到 80px 再叠放；中间牌堆按剩下的高度放大，≥ 168px 时小图按 2 倍显示）；`cards.tsx` 画牌（牌的颜色是 CSS，小图是 PixelLab 画的、`art/export.py` 加的白描边）。
- `scripts/test-bot.mjs`：陪玩机器人（直接用规则包的 `legalActions` / `cardPoints`）。
- `art/`：`art.py` 出候选（14 种牌的小图、头像、徽记、STOP / 最后机会图标、沙滩、首页主图），`fx.py` 出对子效果的小动画（首末帧都用选定的小图，`fxcheck.py` 量逐帧变化、拼帧条检查），`overview.py` / `sticker.py` 拼候选总览（贴在牌色上看效果），`selection.json` 记选中的，`export.py` 导出到 `apps/web/public/art/`（牌面加白描边、动画拼成横排帧条），花费记在 `ledger.jsonl`。`gallery_r1.py` 生成给他挑图的本地画廊（`python -m http.server 8767 --directory art/out/gallery`）。

## 画面：白天版和夜间版

只有像素风一种画面，配色分夜间（深色，默认）和白天（白底）两种。顶栏「切换白天版 / 切换夜间版」随时切换，记在浏览器的 `gm-pixel-theme` 里；gulugagame.com 上的大厅和各个游戏同源，共用这一个选择。牌桌的沙滩也跟着换：白天是晴天沙滩，夜间是月光沙滩。

- 夜间配色就是 `app-pixel.css`（首页和等候房间）和 `seasalt.css`（牌桌）本身。白天版由 `apps/web/day-theme.ts`（Vite 插件）在构建时按 `apps/web/day-palette.ts` 的调色表生成；新出现的深色要在调色表里补一行。牌面（`ss-card`）和颜色色块在 `keep` 里，不换色。
- 机械换色不合适的地方在 `apps/web/src/theme-day.css` 里手写。

## 部署

服务器上 `~/seasalt`，pm2 进程 `seasalt`（端口 3011），网页在 `/var/www/seasalt`，Caddy `handle_path /seasalt/*`（也在付费网关 `@games` 里）。本机运行 `~/projects/deploy.sh seasalt`（服务器拉 GitHub 上的 main）。

pm2 按仓库根目录的 `ecosystem.config.cjs` 直接启动一个 `node --import tsx` 进程跑服务端（不经过 `npm start`）。端口和密钥存在 pm2 里，不进仓库。
